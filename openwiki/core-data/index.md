# Files

- [Activity results](activity-result.md) - How com.core.data.activityResult turns AndroidX ActivityResultContracts into suspend functions callable from any layer, including the registry, SavedStateRegistry and recreation mechanics and every convenience extension.
- [Analytics](analytics.md) - Reference for com.core.data.analytics. Covers the IAnalyticsManager facade that routes views and events to analytics frameworks registered in a Hilt map keyed by AnalyticsFramework, the Firebase implementation, the event/view model hierarchy, and how to add frameworks.
- [Cache: memory and encrypted disk scopes](cache.md) - Reference for com.core.data.cache. Covers ICacheManager over a Hilt map of cache scopes (in-memory LruCache and AES-encrypted Preferences DataStore), cache configs with TTL or infinite lifetime, expiry, serialization rules, and the repositoryPattern helper.
- [Downloads](download.md) - Reference for com.core.data.download. Covers IDownloadManager.requestDownload, which resolves extension and MIME type, returns an already-saved local file if present, and otherwise streams the URL through a Retrofit DownloadApiService and saves it with IFileManager.
- [Environment](environment.md) - Reference for com.core.data.environment. Covers the Environment sealed class (DEV, UAT, PROD with default API URLs), the mutable singleton IEnvironmentManager that defaults to DEV, and how the selected environment feeds Retrofit base URLs and the SSL pinning decision when the network singletons are created.
- [File storage](file.md) - Reference for com.core.data.file. Covers IFileManager.saveFile and findFile, which store and look up files in the app's internal filesDir (PDFs under documents/), handle legacy storage permission requests, and return FileProvider content URIs via the manifest-declared provider and provider_paths.xml.
- [Network: Retrofit, ApiResult and SSL](network.md) - Reference for com.core.data.network. Covers the ApiResult sealed result type used across core/data, the Retrofit call adapter that turns suspend service methods into ApiResult, safeApiCall, the ApiResult extension operators, the Hilt network graph (OkHttp, JSON converter, Retrofit.Builder, RetrofitFactory/RetrofitBuilder) and environment-driven SSL pinning.
- [Notifications](notifications.md) - Reference for com.core.data.notifications. Covers INotificationsManager, which requests and checks the POST_NOTIFICATIONS runtime permission and removes an active status-bar notification by tag. It doesn't build or post notifications.
- [core/data module overview](overview.md) - Overview of the core/data Android library (namespace com.core.data). Covers its 12 packages, the I*Manager/*Impl + Hilt SingletonComponent conventions and multibinding maps, cross-package dependencies, the CoreDataPlugin build setup, how other modules consume it, and its manifest, resources and ProGuard files.
- [Permissions](permission.md) - Reference for com.core.data.permission. Covers IPermissionManager, which checks runtime permissions against the application context and requests single or multiple permissions through IActivityResultManager, mapping results to Granted, Denied or ShowRationale. Also covers the fallback when no activity is available.
- [Recipes for feature work on core/data](recipes.md) - Step-by-step Kotlin recipes for building features on core/data. Covers adding Retrofit services and handling ApiResult, caching with repositoryPattern, analytics frameworks and events, AES/RSA encryption, session lifecycle and commands, permissions, activity results, downloads and files, environment switching, and notification permission and dismissal.
- [Security: AES/RSA cryptography](security.md) - Reference for com.core.data.security. Covers ISecurityManager, which dispatches encrypt and decrypt by CipherType to AES (AndroidKeyStore AES/GCM or caller key) and RSA (AndroidKeyStore key pair or caller X.509/PKCS#8 keys) implementations registered in a Hilt map. Includes formats, key aliases, error behaviour and how to add cipher types.
- [Session management](session.md) - Reference for com.core.data.session. Covers ISessionManager, which holds the logged-in user/token in the memory cache, tracks Active/Inactive state, and runs an inactivity CountDownTimer that emits Warning and TimeOut SessionCommands through a conflated channel, plus how core/presentation's BaseActivity consumes them.
- [Testing core/data](testing.md) - How core/data is unit-tested with Robolectric, Hilt testing and MockK. Covers BaseTest, Gradle test configuration, the android.util.Base64 JVM shadow, every test helper, what each test class covers, how modules are replaced, and a template for testing a new manager.
- [ActivityProvider](utils.md) - Reference for com.core.data.utils.ActivityProvider. Covers the process-wide object that registers ActivityLifecycleCallbacks, exposes the application context, and tracks the most recent FragmentActivity as currentActivity and activityFlow. Includes its init contract, lifecycle filtering, and the managers that depend on it.
