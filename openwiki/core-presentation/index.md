# Files

- [CoreApp and BaseActivity](app-and-activity.md) - Reference for core/presentation's application and activity base classes. CoreApp initializes ActivityProvider. BaseActivity is the single-activity host that sets edge-to-edge and night mode, applies Theme, renders the Navigation3 NavDisplay with bottom-sheet/dialog scenes and graph-scoped ViewModels, shows the floating bottom nav bar, and bridges session commands.
- [Base screen architecture: contract, ViewModel, UiResult](base-architecture.md) - How screens are structured in core/presentation. Covers IBaseContract (ViewState, ViewEvent, ViewEffect), BaseViewModel (StateFlow state, event and effect channels, use case runner), UiResult and its extensions, and the legacy BaseFlow helper, with a full screen template for the Navigation3 stack.
- [Components: buttons, badge, alert, amount](components-actions.md) - Reference for core/presentation's action and feedback components. Covers BlockButtonComponent, HyperlinkButtonComponent, IconButtonComponent, BadgeComponent, AlertComponent and AmountComponent, with every parameter, every style/size/family variant and the theme tokens each maps to, plus accessibility behaviour and known issues.
- [Components: container, bottom sheet, lists and paging](components-layout.md) - Reference for core/presentation's layout components. Covers BottomSheetComponent and its styles, NonLazyGridComponent, the PagingResponse model used by withUseCaseScopePaging, and the ContainerComponent, PagingComponent and list Loading/Error helpers, which are currently commented out and not compiled.
- [Components: top nav bar, toolbar, bottom nav bar, tabs, stepper](components-navigation.md) - Reference for core/presentation's navigation chrome. Covers TopNavBarComponent, the collapsing ToolbarComponent with its state and pinned, enter-always and exit-until-collapsed scroll behaviors, the floating BottomNavBarComponent with its inline scroll connection and padding modifier, TabComponent and StepperComponent.
- [Coroutines use case runner](coroutines.md) - Reference for CoroutinesUseCaseRunner, the interface BaseViewModel implements to run use cases. Covers withUseCaseScope for fire-and-forget parallel blocks with loading and error callbacks, withUseCaseScopeLazily for turning an ApiResult call into a StateFlow of UiResult, and withUseCaseScopePaging for building a Paging 3 flow from PagingResponse pages. Also covers the zipWithPreviousCount flow helper.
- [Form field components](form-fields.md) - Reference for every form field composable in core/presentation. Covers text, text area, password, amount (with CurrencyType and AmountVisualTransformation), date, range date and OTP inputs; checkbox, chip and toggle selects; and multi-checkbox, multi-chip and multi-toggle groups. Includes parameters, the state each one binds to, styles and tokens, accessibility and known bugs.
- [Forms: state, validation and transforms](forms.md) - The form model of core/presentation. Covers FormState, BaseFieldState and its text, date, range-date, select and multi-select subclasses, the Validators sealed interface (which validators each state accepts, semantics, messages), Transform, and the isNumeric helper. Includes the validation lifecycle and a complete submit example.
- [Legacy Navigation Compose stack](navigation-legacy.md) - Reference for com.core.presentation.navigation, the older Navigation Compose based stack. Covers graphs, typed entries for screens, dialogs and bottom sheets, the NavigationManager/NavigationIntent direction channel, argument helpers, NavGraphBuilder registration, stability wrappers and the custom Material3 bottom-sheet navigator. Nothing in the app currently uses this stack; BaseActivity runs on navigation3.
- [Navigation 3 (active navigation stack)](navigation3.md) - Reference for com.core.presentation.navigation3, the Navigation3-based stack BaseActivity uses. Covers destinations (NavKey), entries with Render plus dialog and bottom-sheet variants, graphs (launcher, bottom-nav), feature registration through Hilt @ClassKey multibinding in ActivityRetainedComponent, the factory and back-stack manager, graph-scoped ViewModel stores, the bottom-sheet scene strategy, and known pitfalls.
- [core/presentation module overview](overview.md) - Overview of the core/presentation Android library (namespace com.core.presentation). Covers its package map, the single-activity Navigation3 + MVI architecture, the Compose design system, its dependency on core/data, the CorePresentationPlugin build (plugins, api vs implementation dependencies), how the app and feature presentation modules consume it, and its manifest, resources and ProGuard files.
- [Recipes for feature screens](recipes.md) - Step-by-step Kotlin and Compose recipes for building features on core/presentation. Covers a complete Navigation3 screen, dialog and bottom-sheet destinations, bottom-nav tabs, validated forms, loading data into UiResult, paged lists, collapsing toolbars, session-warning handling, and adding design tokens or component styles, with the workarounds the current code requires.
- [Testing core/presentation](testing.md) - The current test setup of core/presentation (an androidTest BaseTest and DefaultTestRunner left over after instrumented-test configuration was removed, and no src/test), what the Gradle plugins provide, and templates for unit-testing BaseViewModels and form states and for Compose UI tests once the missing dependencies are added.
- [Design tokens reference](theme-tokens.md) - Complete value tables for core/presentation's design tokens. Covers the seven color families (10–100 shades), the background, border and content palette roles for light and dark themes at default, medium and high contrast, dp/em/sp dimensions, and the body, display, label and title typography styles at each contrast level.
- [Theme and CompositionLocals](theme.md) - Reference for core/presentation's Theme composable. Covers how it provides LocalColors, LocalPalette, LocalDimensions and LocalTypographies; how it resolves the light/dark palette and system contrast (API 34+ listener); its override of the font scale to 1; the Inter downloadable font family; and how components consume the tokens.
- [UI utilities](ui-utils.md) - Reference for core/presentation's ui/utils package. Covers AccessibilityState and accessibilityFocusTarget, the BorderIndication press/hover/focus indication, ComposableLifecycle and rememberFlowWithLifecycle, conditional Modifier helpers, density conversions, ignoreHorizontalParentPadding, amount helpers (inputToAmount, splitByDecimalSeparator) and isKeyboardOpenAsState.
