# Files

- [Code quality: Detekt and automation](code-quality.md) - How static analysis and wiki automation are set up. Covers the Detekt plugin applied by every convention plugin, configureDetekt (autoCorrect, parallel, sources, HTML report paths), config/detekt/detekt.yml (rule sets and the strict settings that most often fail new code), the ktlint and libraries rule plugins and which modules get them, how to run Detekt, and the scheduled OpenWiki GitHub workflow.
- [Config: Android and JVM settings](config.md) - Reference for com.core.dependencies.config. Covers the Config object and the AndroidConfig and JvmConfig data classes that centralize compile, target and min SDK, application id, version, the default namespace, and the Java and Kotlin JVM target for every module. Includes where each value is read and the consequences of changing it.
- [Dependency visibility matrix](dependency-visibility.md) - Which libraries and project classes are compile-visible in each module type (app, core:data, core:presentation, feature data, feature presentation) and in their unit tests, derived from the convention plugins' api, implementation and test-fixture declarations. Includes the gaps that cause unresolved-reference errors and how to fix them.
- [Build helper extensions](extensions.md) - Reference for every function in com.core.dependencies.utils/Extensions.kt. Covers the coreLibs catalog accessor, both defaultConfiguration overloads, configureDetekt, configureBuildTypes, configurePackaging, configureTests, and the DependencyHandler configuration shortcuts, with the exact values they set, their side effects and which convention plugins call them.
- [core/dependencies overview (build logic)](overview.md) - How BaseApplication's build is organized. Covers the core/dependencies included build that provides five convention plugins and the shared coreLibs version catalog, how the root settings and build scripts consume it, the plugin-to-module map and module graph, gradle.properties and the wrapper version, repository rules, and the leftover files in the included build.
- [Plugin: app](plugin-app.md) - Reference for AppPlugin (plugin id app), the convention plugin for the :app application module. Covers the Gradle plugins it applies, ApplicationExtension configuration (application id, version, debug suffixes, release shrinking signed with the debug key), Compose, its dependencies, and what the app module can and can't see.
- [Plugin: core.data](plugin-core-data.md) - Reference for CoreDataPlugin (plugin id core.data), the convention plugin for the :core:data library. Covers the plugins it applies (including Dokka and Detekt), its Android configuration (it's the only plugin that calls configureTests), and every dependency with its configuration (api serialization and Retrofit, implementation DataStore, Hilt, OkHttp logging and Firebase, the test-unit bundle via test fixtures).
- [Plugin: core.presentation](plugin-core-presentation.md) - Reference for CorePresentationPlugin (plugin id core.presentation), the convention plugin for the :core:presentation library. Covers the plugins it applies (Compose, serialization, KSP, Hilt, Detekt), Compose enablement, every dependency with its configuration (implementation core:data, the many api AndroidX UI libraries, Compose BoM, debug tooling, test fixtures), and the visibility and versioning consequences.
- [Plugin: feature.data](plugin-feature-data.md) - Reference for FeatureDataPlugin (plugin id feature.data), the convention plugin for feature data modules such as :demo:data. Covers the plugins it applies (Android library, serialization, KSP, Hilt, Detekt), its Android configuration, its dependencies (api core:data, Hilt, core:data test fixtures), what it doesn't set up (namespace, Hilt test codegen, Robolectric test config), and a complete module example.
- [Plugin: feature.presentation](plugin-feature-presentation.md) - Reference for FeaturePresentationPlugin (plugin id feature.presentation), the convention plugin for feature UI modules such as :demo:presentation. Covers the plugins it applies (Android library, Compose, serialization, KSP, Hilt, Detekt), Compose enablement, its dependencies (implementation core:presentation, Hilt, core:presentation test fixtures), the core/data visibility gap, and a complete module example.
- [Build recipes](recipes.md) - Step-by-step Gradle recipes for BaseApplication. Covers creating and wiring feature data and presentation modules, adding or upgrading libraries and plugins in the coreLibs catalog, adding bundles, writing a new convention plugin, bumping SDK and JVM levels, enabling unit or Compose UI tests for a module type, and the commands to build and verify.
- [Version catalog (coreLibs)](version-catalog.md) - Every entry in core/dependencies/gradle/libs.versions.toml (the coreLibs catalog). Covers all versions, libraries with Maven coordinates, plugins with ids, and the test-unit bundle, each mapped to the convention plugins, build scripts or modules that use it, with unused and BoM-managed entries flagged.
